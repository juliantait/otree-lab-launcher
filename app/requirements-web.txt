# oTree Lab Launcher (web): dependencies.
#
# As of v1.1.0 the launcher runs in BROWSER MODE by default on every platform:
# it serves its UI over a tiny standard-library HTTP server and opens it in the
# operator's DEFAULT BROWSER. That path needs NOTHING beyond the Python standard
# library (plus the bundled otree_core), so this file installs no third-party
# packages -- and on macOS the launcher starts WITHOUT trying to compile pyobjc.
#
# There are therefore deliberately no required dependencies here.
#
# ---------------------------------------------------------------------------
# OPTIONAL: the native desktop window (pywebview)
# ---------------------------------------------------------------------------
# A native pywebview window is an OPTIONAL opt-in (run the launcher with
# --window / --pywebview). It is NEVER needed for the normal browser-mode path.
# If you want it, install the pinned deps below by hand, e.g.:
#
#     pip install -r app/requirements-web-optional.txt
#
# and see _ai/WEB_FREEZE_DIAGNOSIS.md for the Windows WebView2 / pythonnet
# version matrix. These lines are commented out on purpose so the default
# install never pulls the heavy, fragile native GUI wheels:
#
#   pywebview==5.4
#   pythonnet==3.0.5 ; sys_platform == "win32"        # NEVER 3.0.0 / 3.0.0.post1
#   pyobjc-framework-Cocoa ; sys_platform == "darwin"
#   pyobjc-framework-WebKit ; sys_platform == "darwin"
